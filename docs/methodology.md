# Methodology

This document summarizes the implementation workflow used in the thesis
analysis. It is written as a repository-level explanation rather than a full
replacement for the thesis text.

## 1. Input Data

The working scripts use UAV trajectory data containing vehicle-level records.
The main variables used by the analysis include:

- vehicle identifier,
- local timestamp,
- orthogonal x/y position,
- local x/y position,
- latitude and longitude,
- vehicle class,
- speed,
- acceleration,
- road section,
- lane number,
- visibility.

The public repository does not include the raw trajectory files.

## 2. Movement and Lane Assignment

Vehicles are assigned to intersection movements using road-section and geometry
rules. For the Q intersection, movement codes include:

| Code | Meaning |
| --- | --- |
| NS | North to South |
| SN | South to North |
| ES | East to South |
| EN | East to North |
| NE | North to East |
| SE | South to East |

The thesis-ready labels describe these as through or turning movements, for
example "North Through South Lane A" or "East Turns to South Lane A".

## 3. Space-Time Diagrams

Space-time diagrams are generated by lane and movement. The diagrams plot
vehicle trajectory position against time and overlay inferred signal state
intervals.

These diagrams are used for:

- checking whether vehicles move during inferred green intervals,
- identifying queue discharge behavior,
- visually validating signal phase inference,
- selecting clean windows for composite diagrams.

## 4. Signal Timing Inference

Signal state is inferred from observed trajectory behavior, especially stopped
vehicles and departure events. The workflow distinguishes:

- protected movements,
- permissive movements,
- green intervals,
- red intervals,
- certain red intervals where a standing queue is observed.

For headway analysis, green intervals are only considered valid when they follow
a certain red interval, because startup discharge modelling requires an actual
standing queue.

## 5. Headway and Saturation Flow

For valid green intervals, departure times are ordered by queue position.
Interdeparture headway is computed as:

```text
h_i = t_i - t_{i-1}
```

The saturation headway is estimated from later queue positions:

```text
h_sat = mean(h_i for i >= 5)
```

The saturation rate is:

```text
r_sat = 1 / h_sat
```

The time until saturation is represented as:

```text
t_C
```

where `t_C` is the same concept as the time until saturated discharge behavior
is reached.

## 6. Traffic Light Model Validation

The final validation table compares observed lane-cycle vehicle counts with a
modelled count. The plotted pairwise validation uses:

```text
x = observed vehicle count, N_veh
y = modelled vehicle count, f(t_G)
```

The capped median validation model is:

```text
f(t_G) = r_sat_median * min(max(0, t_G - t_C), active_discharge_time)
```

where:

- `t_G` is the green interval duration,
- `t_C` is the time until saturation,
- `r_sat_median` is the median saturation rate for the movement group,
- `active_discharge_time` is the observed active discharge duration within the
  green interval.

The summary table reports mean absolute error for the selected validation rows.
